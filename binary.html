HOW TO CODE GAMES IN PURE BINARY

Every instruction in this machine is 8 bits (1 byte) long. The CPU splits each instruction byte into two halves:

  • First 4 bits (Opcode): Tells the CPU what operation to perform.
  • Last 4 bits (Operands): Tells the CPU which registers to use. Registers are addressed in 2 bits: R0 = 00, R1 = 01, R2 = 10, R3 = 11.

Complete Binary Opcode Table

Binary Opcode Format (8 Bits) Next Byte? What It Does
0000 0000 0000 No HALT: Stops the CPU completely.
0001 0001 [AA] 00 Yes (Value) LOAD IMMEDIATE: Loads the next byte directly into Register AA.
0010 0010 [AA] 00 Yes (Address) LOAD RAM: Reads RAM at the given address and puts it in Register AA.
0011 0011 [AA] 00 Yes (Address) STORE RAM: Writes Register AA into RAM at the given address.
0100 0100 [AA] [BB] No STORE POINTER: Writes Register AA into the RAM address stored inside Register BB. (Used for drawing pixels!)
0101 0101 [AA] [BB] No ADD: Adds BB to AA (AA = AA + BB).
0110 0110 [AA] [BB] No SUBTRACT: Subtracts BB from AA (AA = AA - BB).
0111 0111 [AA] [BB] No COMPARE: Sets Zero Flag to 1 if AA == BB, otherwise 0.
1000 1000 0000 Yes (Address) JUMP: Sets Program Counter to the next byte (creates loops).
1001 1001 0000 Yes (Address) JUMP IF ZERO: Jumps to the next byte only if Zero Flag is 1.
1010 1010 0000 Yes (Address) JUMP IF NOT ZERO: Jumps to the next byte only if Zero Flag is 0.
1011 1011 [AA] 00 No SHIFT LEFT: Shifts bits in AA left (moves pixels left).
1100 1100 [AA] 00 No SHIFT RIGHT: Shifts bits in AA right (moves pixels right).
1101 1101 [AA] [BB] No BITWISE OR: Combines bits of AA and BB (great for drawing two sprites on the same row!).
1110 1110 [AA] [BB] No BITWISE XOR: Toggles bits (great for collision detection!).
1111 1111 [AA] [BB] No MOVE: Copies value from BB into AA.

Hardware Memory Map

  • Bytes 00000000 to 11101110 (0–238): Your game code and variables.
  • Byte 11101111 (239): Keyboard Input Port. Automatically becomes 00000001 (W), 00000010 (S), 00000011 (A), or 00000100 (D) when pressed.
  • Bytes 11110000 to 11111111 (240–255): Video RAM. Each byte represents one horizontal row of the screen from top (240) to bottom (255). Every 1 bit turns a pixel green; every 0 bit turns it black.
