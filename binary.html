[0101] 8-BIT BINARY GAME STUDIO

Use Arrow Keys to play!

1. Binary Code Editor (8-Bit Instructions)

Status: Ready

2. 16x16 Pixel Screen

X: 0 | Y: 0 | Enemy: (0,0)

3. Binary Instruction Manual

Every instruction is 8 bits long:
[4-bit Opcode] [4-bit Value]

Spaces and text after ; are ignored (comments).

OpcodeAction
0000Clear Screen
0001Set Player X (0000-1111)
0010Set Player Y (0000-1111)
0011Draw Player (Value = Color 1-7)
0100Move Player on Arrow Key
0101Draw Pixel at Enemy X,Y (Color)
0110Move Enemy Down (Wraps at bottom)
0111Reset Game if Player hits Enemy
1111Loop back to start (60 FPS)

Colors (4-bit):
0001 Red | 0010 Green | 0011 Blue
0100 Yellow | 0111 White
